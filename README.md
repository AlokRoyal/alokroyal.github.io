# Alok Roy — Portfolio Website

![HTML](https://img.shields.io/badge/HTML5-static%20site-E34F26?logo=html5&logoColor=white)
![GitHub Pages](https://img.shields.io/badge/deploy-GitHub%20Pages-222222?logo=githubpages&logoColor=white)

A static personal portfolio and project showcase published as a GitHub Pages user site. The homepage introduces Alok Roy and links to selected projects; the About Me page contains additional profile information.

## What visitors can find

- A short personal introduction
- Featured projects linking to their GitHub repositories
- Social profile links
- A separate About Me page

## Architecture

Browser → index.html / projects.html → bundled CSS and JavaScript in assets/ → local images

The site is built as static HTML with assets from the Massively template by HTML5 UP. It does not need a build system or application server.

## Preview and publish

Open index.html locally to preview. For GitHub Pages, retain the repository name AlokRoyal.github.io and publish from the repository’s configured Pages source. The HTML pages, assets/, and images/ directories must remain together at the published root.

## Project layout

- index.html — landing page and project cards
- projects.html — profile/about content
- assets/ — template stylesheets, scripts, fonts, and supporting files
- images/ — portrait and project imagery
- README.txt — original template notes and credits
- LICENSE.txt — included licensing terms
